当前判定与《产品需求》一致：

- PERFECT 是 ±60 毫秒。
- GOOD 是 ±130 毫秒。
- 早于 -130 毫秒、但不早于 -200 毫秒的按下是 EARLY MISS。
- 早于 -200 毫秒的按下被忽略。
- 长按在尾巴前 80 毫秒到尾巴后 200 毫秒之间松开是 PERFECT，仍得 100 分。
- 再早松开是 MISS。
- 晚于尾巴 200 毫秒仍按着，或这时才松开，是 GOOD，也得 100 分。

`npm test` 在这次判定调整后通过，共 12 个测试。

## 5. 本地运行

在项目目录执行：

```text
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。不要双击 `index.html`，那个文件离开 Vite 就是白屏。

其他命令：

| 命令 | 作用 |
| --- | --- |
| `npm test` | 跑判定和准确率测试 |
| `npm run build` | 类型检查并生成生产文件 |
| `npm run generate` | 重写测试谱和测试音频 |

替换正式曲目前，把新的 `chart.json` 和音频文件放到 `public/`，文件名保持 `chart.json` 与 `audio.wav`，然后刷新页面。音频如果不是 WAV，还要同时改 `src/App.tsx` 里的请求路径。
