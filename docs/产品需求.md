# BPs 产品需求

日期：2026-11-06

BPs 是一款网页节奏游戏，非商业、不盈利。玩家对着音乐，在四条下落轨道上敲击单键和长按。谱面最终由用户自制并在线游玩；第一阶段只在本机游玩一首已经放进项目里的测试曲。

本文记录已经定下来的规则。判定窗口在实际游玩后放宽过，以本文数字为准。

## 1. 阶段

| 阶段 | 玩家能做什么 | 状态 |
| --- | --- | --- |
| 第一阶段 | 本机游玩、改流速 / 偏移 / 键位、看结算 | 已实现，见《当前进度》 |
| 之后 | 谱面列表、注册登录、上传、下架、单曲排行榜 | 规则已定，尚未实现 |
| 更后 | 界面打磨、中文和其他语言 | 只定了方向 |

第一阶段保证能玩。上网、真实歌曲、界面优化都排在后面。

## 2. 第一阶段

### 2.1 页面流程

开始页有两个入口：Play、Settings。界面文字用英文，字体用系统无衬线体。布局是黑灰极简。

- Play 读取项目里的 `chart.json` 和 `audio.wav`，解码成功后直接进入游戏。加载失败时回到开始页，并说明原因。
- Settings 改的是全局设置，对所有谱面生效。进游戏后不再询问设置。
- 游戏中按 Esc 暂停。暂停页有 Resume 和 Quit。
- Quit 回到开始页，不进入结算。
- 一首曲子在全部音符结算完成，且音频时钟走到音频时长之后，进入结算。
- 结算显示曲名、Score、Accuracy、Max Combo、PERFECT、GOOD、MISS。第一阶段没有 Rank。
- Retry 用已经加载好的谱面和音频立刻再开一局。Back 回到开始页。
- 浏览器标签被隐藏时自动暂停。

### 2.2 轨道和画面

四轨，下落式。设计坐标系宽 400、高 800，判定线在 y = 700。画面放在一条高度为视口 90% 的竖栏里，宽度是高度的一半，居中，整体等比缩放。每条轨道宽 100。

| 元素 | 规格 |
| --- | --- |
| 背景 | `#101010` |
| 轨道 | `#161616` 与 `#1e1e1e` 交替 |
| 判定线、单键、长按头 | `#f0f0f0` |
| 长按身体 | `#5c5c5c` |
| 按下的判定区 | `#3a3a3a` |
| 文字 | `#e8e8e8` |
| PERFECT | `#f5f5f5` |
| GOOD | `#8d8d8d` |
| MISS | `#5c5c5c` 描边 |
| 单键 | 高 28，左右各留 10 |
| 判定区 | 判定线以下 100 像素，显示该轨键位名 |
| Combo | 顶部居中 |
| 判定文字 | 判定线上方，EARLY / LATE 在等级上方 |
| 判定文字持续时间 | 500 毫秒 |

音符只画在判定线以上。长按头部命中后，身体下端停在判定线。提前松开的长按改成从松开位置到尾巴的空心条。

没有血量，没有打击音效。

### 2.3 时间

音频时钟是唯一的时间基准。按键在按下或松开到达时立刻判定，不等下一帧。按键连发无效。四条轨道互不影响。空按没有惩罚。

时间差：

`dt = 音频时间 - (音符时间 + 偏移)`

偏移为正时，音符应当更晚击中。偏移为 0 时，游戏默认认为谱面已经和音乐对齐。

流速 S 的范围是 1.0 到 6.0，步进 0.1，默认 3.0。音符从出现到抵达判定线的时间是 `3600 / S` 毫秒。默认 3.0 对应 1200 毫秒。

开局先有一段与当前流速相同的预备时间。偏移为 0 时，时间为 0 的音符从轨道顶端进入。这段开局预备会计入判定。

暂停时音频和时钟都停，暂停期间不判定。继续时先静音倒回一段预备，长度同样是当前出现时间；预备期间不判定。预备走完、回到暂停点时，按当时真实的按键状态结算：长按键已经松开的，按暂停点的时间松开。

音频结束后，时钟还可以再走 150 毫秒，用来关上还开着的判定窗口。

### 2.4 单键判定

只打本轨时间最早、窗口仍开着的音符。头部必须是一次新的按下；提前按住不算。

| dt | 结果 |
| --- | --- |
| 小于 -200 | 忽略，音符继续等待 |
| -200 到 -130 之间，含 -200 | EARLY MISS，吃掉这颗音符 |
| -130 到 -60 之间，以及 60 到 130，含两端 | GOOD |
| -60 到 60，含两端 | PERFECT |
| 大于 130 | 这次按键不吃音符；时钟越过 130 后自动 LATE MISS |

### 2.5 长按判定

长按有头部和尾部。头部使用单键窗口。头部 MISS 时尾部直接 MISS，不产生中间连击，MISS 记两次。

尾部的 PERFECT 窗口不对称。显示的长条在尾巴时间到达判定线，判定在那之后还继续：

| 松开时间 | 结果 |
| --- | --- |
| 早于尾巴时间 80 毫秒以上 | EARLY MISS，长按条从松开处断开 |
| 尾巴前 80 毫秒之内，到尾巴后 200 毫秒，含两端 | PERFECT |
| 晚于尾巴 200 毫秒才松开 | GOOD |
| 一直按住，直到晚于尾巴 200 毫秒 | GOOD，不标 LATE |

尾巴结算之后，下一颗音符需要一次新的按下。长按可以短于判定窗口。

### 2.6 分数、连击、准确率

| 判定 | 分数 | 连击 |
| --- | --- | --- |
| 头部 PERFECT | 100 | +1 |
| 头部 GOOD | 50 | +1 |
| 尾部 PERFECT | 100 | +1 |
| 尾部 GOOD | 100 | +1 |
| 任何 MISS | 0 | 归零 |

一颗单键满分 100。一条长按满分 200，相当于两颗单键。满分等于单键数乘 100，加上长按数乘 200。

按住期间，每经过 100 毫秒音频时间加 1 连击。这些连击必须严格发生在尾巴时间之前，不计分，也不计入 PERFECT / GOOD / MISS 的个数。MISS 之前已经打出的连击仍然计入最大连击。

准确率显示直接丢掉第三位小数，不四舍五入。`99.286%` 显示为 `99.28%`。`9998 / 10000` 显示为 `99.98%`。只有分子和分母的比值正好是 100% 时才显示 `100.00%`。以后做排名时比较精确比值，不比较这段显示文字。

## 3. 设置

设置保存在本机，键名 `bps-settings`。第一次打开使用默认值。四个键位必须互不相同；选到已被占用的键时，两条轨道对调。

| 项 | 默认 | 范围 | 操作 |
| --- | --- | --- | --- |
| Speed | 3.0 | 1.0–6.0，步进 0.1 | 加减按钮 |
| Offset | 0 | 整数 -200–200 毫秒 | 直接输入，或每次 1 毫秒 |
| 四条键位 | D F J K | A–Z、0–9、Space、Semicolon、Comma、Period | 鼠标下拉 |

键位存成小写。Esc 只用于暂停，不能绑成游戏键。游戏键只在对局中生效。

## 4. 谱面

第一阶段没有选曲。浏览器读取固定的两个文件：谱面 JSON 和音频。现在这两个文件是 14 秒测试音和与之对齐的测试谱，只用来核对时机。真实歌曲以后由使用者提供音频，再生成对应 JSON，替换这两个文件后刷新即可。

JSON 字段：

| 字段 | 要求 |
| --- | --- |
| `title` | 非空字符串 |
| `recording` | 字符串，录音或曲目名称 |
| `notes` | 至少一颗音符 |
| `notes[].lane` | 整数 0–3 |
| `notes[].time` | 毫秒，大于等于 0，不超过音频时长 |
| `notes[].end` | 可选。存在时必须大于 `time`，且不超过音频时长 |

同一轨的 `time` 不能重复。同一轨上，下一颗音符的时间必须晚于上一颗长按的 `end`。

## 5. 谱面社区

这一节是已经定稿、尚未实现的规则。

游戏不自带正式谱面。公开列表按上传时间从新到旧，每页 50 首，没有搜索。不登录也可以玩。要上传或保存成绩才需要登录。

### 5.1 账号

- 用户名 3–20 位，只含字母、数字、下划线，大小写不敏感，必须唯一。
- 邮箱必须唯一，不验证。
- 密码至少 8 位，注册时要再输入一次。
- 登录可以用用户名或邮箱，加上密码。
- 登录状态保持到主动 Log out。
- 没有找回密码，没有注销账号，没有第三方登录。

### 5.2 上传、下架、权利

上传一份 JSON，加一份 mp3 或 ogg，合计不超过 15MB。音频必须能完整解码。上传前确认这段英文声明：

> This project is non-commercial. Charts and audio are uploaded by users. If a rightsholder asks us to take something down, the chart will be unpublished immediately. The page and leaderboard will remain, and the chart will no longer be playable.

作者可以 Unpublish。确认文案是 “Unpublish this chart?”。下架后谱面从列表消失，但地址还在，曲名、录音名、上传者和排行榜保留，页面显示 “This chart is unpublished.”。不能 Play，不提供音频，不能提交新成绩。作者可以再次 Publish，除非谱面被权利锁定。

配置里的管理员邮箱可以看到 “Allow publish”。它只解除权利锁。页面提供 mailto 的 Request removal。

### 5.3 排行榜

每首谱面保留最好的 100 个成绩。排序依次是：分数更高、精确准确率更高、最大连击更高、达成时间更早。结算页的 Rank 可以大于 100。未登录时显示 “Log in to save your score.”。

没有回放，没有反作弊，没有全站排行榜，没有个人主页，没有谱面编辑器，没有多人游戏。

## 6. 声明

本项目非商业。谱面和音频由用户上传。权利人要求下架时，谱面立即改为不可游玩；页面和排行榜保留。
